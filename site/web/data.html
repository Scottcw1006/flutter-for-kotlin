資料類別與 JSON

說明

第 2 章提過 Dart 沒有 data class。實務上用 freezed 產生 copyWith、==、hashCode、toString，再用 json_serializable 產生 fromJson、toJson：

  • 寫一個 const factory 建構子描述欄位，產生出來的程式碼放在 part 宣告的 *.freezed.dart 和 *.g.dart 裡。
  • 改了類別之後要執行 dart run build_runner build，或開著 dart run build_runner watch 讓它自動重新產生。這是跟 KSP 最大的差別：KSP 跟著 Gradle 建置自動跑。
  • 欄位名稱跟 JSON 不同時，用 @JsonKey(name: 'user_name')，對應 @SerialName。

預設行為相反：json_serializable 會直接忽略 JSON 裡多出來的欄位（例如上面的 phone）；kotlinx.serialization 預設會丟例外，所以 Kotlin 版要設定 ignoreUnknownKeys = true。

HTTP 請求：dio 與 Retrofit

說明

dio 的角色相當於 OkHttp 加上一部分 Retrofit：BaseOptions 設定 base URL 與逾時，interceptor 處理登入 token 與 log。它沒有 Retrofit 那種「寫介面、自動產生實作」的機制，一般是自己包一個 API 類別，如右邊的 UserApi。想要 Retrofit 的寫法，可以用 retrofit 這個 Dart 套件產生程式碼。

  • dioProvider → userApiProvider → usersProvider 是一條依賴鏈，相當於 Hilt 裡 OkHttpClient 注入 Retrofit、再注入 Repository。測試時 override userApiProvider 就能換成假資料。
  • 錯誤會以 DioException 拋出。Riverpod 3 會先自動重試幾次（期間仍顯示載入中），重試用完才變成 AsyncError，畫面再顯示「重試」按鈕。上一頁的非同步狀態有說明這個預設行為。
  • RefreshIndicator 對應 PullToRefreshBox；ref.refresh(provider.future) 會重新執行並回傳新的 Future，下拉的轉圈會等它完成才收起來。

在網頁上執行時，請求會受瀏覽器的 CORS 限制，所以這裡選了允許跨網域的測試 API。Android 和 iOS 上沒有這個限制。

release 版要自己加上網路權限。flutter create 只在 android/app/src/debug/ 和 profile/ 的 AndroidManifest.xml 宣告了 INTERNET（給 hot reload 與除錯工具用），正式版用的 src/main/AndroidManifest.xml 裡沒有。所以會出現「debug 版一切正常，release 版所有請求都失敗」的情況。用到網路的 App，要在 src/main/AndroidManifest.xml 的 <manifest> 底下加上：

<uses-permission android:name="android.permission.INTERNET" />

簡單設定值：shared_preferences 與 DataStore

說明

存少量的設定值（深色模式、上次選的分頁），DataStore Preferences 對應 shared_preferences。它的底層依平台而定：在 iOS 上是 NSUserDefaults，在網頁上是 localStorage。在 Android 上，這裡用的 SharedPreferencesAsync 預設存在 DataStore Preferences，跟 Compose 這邊是同一套；舊的 SharedPreferences.getInstance() API 才是存在 Android 的 SharedPreferences。兩種 API 的資料互不相通，換 API 時舊資料不會自動搬過去。

  • 建議使用新的 SharedPreferencesAsync（每次都非同步讀寫），或 SharedPreferencesWithCache。舊的 SharedPreferences.getInstance() 會把資料快取在記憶體裡，多個 isolate 同時讀寫時可能不一致。
  • DataStore 的 data 是一個 Flow，值改了會自動送出新值；shared_preferences 沒有變更通知，所以這裡用 AsyncNotifier 自己保存目前的值，寫入時先更新 state 再存檔。
