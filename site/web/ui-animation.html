動畫

兩邊的動畫 API 都分成兩層：簡單的「值變了就自動補間」，以及可以完全控制的「動畫控制器」。Compose 用 animate*AsState 和 Animatable；Flutter 用一系列 Animated* widget 和 AnimationController。

隱式動畫：AnimatedContainer

說明

Compose 是把每個要動的值包進 animate*AsState；Flutter 則是換成會動的 widget：把 Container 換成 AnimatedContainer，它的寬高、顏色、圓角、padding 只要一改變，就會自動補間到新的值。

  • Flutter 的隱式動畫一定要給 duration，曲線用 curve 指定。Compose 的預設是 spring，Flutter 的預設則是固定時間長度的補間。
  • 常用的還有 AnimatedOpacity、AnimatedPadding、AnimatedAlign、AnimatedDefaultTextStyle。沒有現成 widget 的屬性，就用 TweenAnimationBuilder 自己補間。

內容切換：AnimatedSwitcher

說明

AnimatedSwitcher 對應 AnimatedContent：子元件換成另一個時，舊的淡出、新的淡入。轉場效果用 transitionBuilder 自訂，相當於 transitionSpec。

記得給 key。AnimatedSwitcher 是比較新舊子元件的型別和 key 來判斷「內容換了沒」。前後都是 Text、又沒有 key，它會認為是同一個元件，只更新文字、不播放動畫。Compose 的 AnimatedContent 則是比較 targetState，所以不需要這一步。

尺寸變化：AnimatedSize

說明

Modifier.animateContentSize() 對應把內容包進 AnimatedSize。內容變多或變少時，外框會平滑地長大或縮小。

注意 Column 的 mainAxisSize: MainAxisSize.min。Flutter 的 Column 預設會撐滿父層給的最大高度，Compose 的則是包住內容。少了這一行，卡片不管展開或收合都會一樣高，AnimatedSize 就沒有東西可以動畫了。

if (_expanded) ... 是 collection if，直接把展開後才有的子元件寫在 children 裡。這種「顯示或不顯示」的情境，在 Compose 會用 AnimatedVisibility，Flutter 則通常用 AnimatedSize 或 AnimatedSwitcher 來處理。

顯式動畫：AnimationController

說明

需要暫停、重播、循環或依手勢控制的動畫，就要用 AnimationController，它對應 Compose 的 Animatable。它在 0 到 1 之間依時間變化，由你呼叫 forward()、reverse()、repeat()、stop() 控制。

  • vsync：controller 需要有人在每一幀通知它，這就是 SingleTickerProviderStateMixin 的作用。Compose 的動畫自動使用 frame clock，Flutter 要明確接上。所在的頁面被其他頁面蓋住時，ticker 也會跟著暫停，節省資源。
  • 一定要 dispose()：Compose 的 LaunchedEffect 會隨著離開組合自動取消；Flutter 的 controller 不會自動釋放，忘了 dispose() 會造成記憶體洩漏，debug 模式也會報錯。
  • RotationTransition、FadeTransition、SlideTransition 這類 *Transition widget 直接接收 controller，每一幀只更新繪製，不會重新執行 build()。效果跟 Compose 在 graphicsLayer { } 裡讀取動畫值一樣，都是為了避開不必要的重建。自訂效果可以用 AnimatedBuilder。
