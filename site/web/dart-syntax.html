語法對照

Dart 和 Kotlin 都是靜態型別、有型別推論、內建 null safety 的現代語言，大部分語法可以一對一轉換。真正需要重新適應的是幾個習慣：型別寫在前面、分號要寫、沒有 data class，以及可見性用底線表示。

這一章的實際呈現是一個小型 console：右邊的 Dart 函式會真的在瀏覽器裡執行，print() 的輸出顯示在畫面上。可以對照左邊的 Kotlin，想想它會印出什麼。

  • 字串模板跟 Kotlin 完全一樣：$name、${運算式}。Dart 慣例用單引號。
  • 命名慣例是 lowerCamelCase，常數也一樣，不用全大寫。
  • const 比 Kotlin 強：不只是基本型別，物件與集合也能是編譯期常數，例如 const [1, 2]、const Text('Hi')。相同的 const 值在整個程式只會有一份，這也是 Flutter widget 盡量寫 const 的原因。

Dart 的 List 預設可以修改。Kotlin 的 listOf() 是唯讀的，要修改得明確用 mutableListOf()；Dart 的 [1, 2, 3] 直接就能 add()，final 只代表變數不能重新指定。要唯讀的集合就寫 const [...] 或 List.unmodifiable(...)。

函式與具名參數

說明
  • 回傳型別寫在函式名稱前面。單一運算式的函式用 =>，相當於 Kotlin 的 = 運算式。
  • 具名參數要宣告在 {} 裡，而且呼叫時一定要寫名稱。反過來，一般的位置參數不能用名稱呼叫。Kotlin 的任何參數都能具名，這是最大的不同。
  • 具名參數預設是選填的：要嘛給預設值，要嘛型別可為 null，必填就加 required。Flutter 的 widget 建構子幾乎都是具名參數。
  • 選填的位置參數放在 [] 裡，例如 String greet(String name, [String? greeting])，用得比較少。
  • lambda 寫成 (x) => x * 2 或 (x) { return x * 2; }，沒有隱含的 it，大括號版本要明確寫 return。
  • 擴充函式寫在 extension 名稱 on 型別 { } 區塊裡。

Dart 的 if 是陳述式，不是運算式，所以 val mark = if (excited) "!" else "." 要改寫成三元運算子 excited ? '!' : '.'。需要多分支時，Dart 3 的 switch 運算式可以取代 when，下面的 sealed class 小節會用到。

說明

Smart cast 的範圍比較小。Dart 只會自動轉型區域變數和私有的 final 欄位。像 user.email 這種公開欄位，即使檢查過不是 null，下一行仍然被當成 String?，因為它可能被子類別用 getter 覆寫。慣用做法是先存進區域變數，如上面的 final e = user.email;。

類別、data class 與 record

說明
  • 欄位要另外宣告，建構子用 this.x 直接把參數存進欄位。
  • Dart 沒有 data class。==、hashCode、toString、copyWith 都要自己寫。實務上會用 freezed 這類套件自動產生，原理就像 KSP 產生程式碼。第 4 章的待辦 App 會用到。
  • Dart 3 的 record 可以取代 Pair、Triple：(int, int) 是匿名的，({int min, int max}) 是具名欄位的版本。record 自帶結構相等，也可以直接解構。

sealed class 與 pattern matching

說明

用 sealed class 表示「載入中、成功、失敗」這類狀態，在 Kotlin 和 Dart 都是標準做法。Dart 3 的 switch 運算式對應 when，一樣會檢查是否涵蓋所有子類別。

  • Dart 沒有巢狀類別，子類別都寫在頂層，而且必須和 sealed class 在同一個檔案。
  • 不要把子類別取名為 Error，它會蓋掉 Dart 內建的 Error 類別，所以這裡改叫 Failure。
  • Pattern 比 is 檢查更強：Success(:final items) 會同時比對型別並取出欄位；Success(items: []) 直接比對「items 是空 list」。條件判斷可以加在 pattern 後面：Success(:final items) when items.length > 10。

集合操作

說明
  • 字面值：[] 是 List，{'a': 1} 是 Map，{'a', 'b'} 是 Set。注意空的 {} 是 Map。
  • collection if / for 可以直接寫在字面值裡，取代 buildList { }。Flutter 的 children: [...] 經常這樣用，例如待辦 App 裡的 for (final todo in _todos) TodoTile(...)。
  • ... 是 spread，把另一個集合展開進來。
  • 方法名稱：filter 改叫 where，all 改叫 every，firstOrNull { } 對應 firstWhereOrNull（在 package:collection）。groupBy 這類進階函式也在 package:collection。

where、map 是惰性的。它們回傳 Iterable 而不是 List，行為像 Kotlin 的 Sequence：不讀取就不執行，而且每次走訪都會重新執行一次。要當成 List 用、或會走訪多次時，記得加上 .toList()。
