圖片、資源與多語系

Android 把圖片、字串、字型都放在 res/，由 Gradle 產生 R 類別存取。Flutter 沒有 res/：圖片與字型在 pubspec.yaml 宣告，用路徑字串載入；翻譯字串則放在 .arb 檔，由工具產生一個有型別的類別，角色就像 R.string。

圖片：打包的與網路的

說明

打包在 App 裡的圖片，要先在 pubspec.yaml 宣告所在的資料夾：

flutter:
  assets:
    - assets/images/

不同螢幕密度的版本，放在同名檔案的 2.0x/、3.0x/ 子資料夾裡，Flutter 會自動挑選，跟 Android 的 drawable-xhdpi、drawable-xxhdpi 是同樣的機制：

AndroidFlutter
res/drawable-mdpi/app_icon.pngassets/images/app_icon.png
res/drawable-xhdpi/app_icon.pngassets/images/2.0x/app_icon.png
res/drawable-xxhdpi/app_icon.pngassets/images/3.0x/app_icon.png
painterResource(R.drawable.app_icon)Image.asset('assets/images/app_icon.png')
Coil 的 AsyncImageImage.network(url)
  • 路徑是字串：沒有 R.drawable 那樣的編譯期檢查，打錯字要到執行時才會發現。需要型別安全時，可以用 flutter_gen 從 pubspec.yaml 產生資源類別。
  • 網路圖片的快取：Image.network 只有記憶體快取，App 重開就要重新下載。正式的 App 通常改用 cached_network_image，它會存到磁碟，用法和 Coil 很接近。
  • 向量圖：Flutter 不支援 Android 的 VectorDrawable。SVG 用 flutter_svg 顯示；Material 圖示則已經內建在 Icons 類別裡，不用像 Compose 那樣另外加 material-icons-extended。

App 圖示、啟動畫面與字型

說明
  • App 圖示：仍然是 android/app/src/main/res/mipmap-* 裡的原生資源。手動替換很繁瑣，一般用 flutter_launcher_icons，從一張大圖產生 Android（含 adaptive icon）與 iOS 需要的所有尺寸。
  • 啟動畫面：引擎載入期間顯示的是原生的啟動畫面，Android 12 以上由系統的 Splash Screen API 處理。flutter_native_splash 可以一次產生兩個平台的設定。
  • 字型：字型檔放進專案，在 pubspec.yaml 的 fonts 宣告字型家族與字重，再用 TextStyle(fontFamily: …) 或 ThemeData(fontFamily: …) 使用，對應 Android 的 res/font。這個網站本身就用這個方式內附了一份中文字型。

多語系：strings.xml 與 .arb

說明

Flutter 官方的多語系流程，是把翻譯寫在 .arb 檔（JSON 格式），由 flutter gen-l10n 產生 AppLocalizations 類別。設定步驟：

  1. 加入套件：flutter pub add flutter_localizations --sdk=flutter 與 flutter pub add intl。
  2. 在 pubspec.yaml 的 flutter: 底下加上 generate: true，建置時就會自動產生程式碼。
  3. 在專案根目錄新增 l10n.yaml，指定 .arb 檔的位置與哪一個語言是範本：
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart

系統依語系自動選擇沒有指定 locale 時同樣跟隨系統語系

複數規則的一個差別：Android 的 plurals 只能用語言本身的數量類別，中文只有 other 一種，所以「0 件」要另外寫一個字串、在程式裡判斷。ICU 格式可以直接寫 =0{…}，任何語言都能針對特定數字給專門的句子。

Android 13 的「個別 App 語言」設定，需要在 android/app/src/main/res/xml/ 加上 locales_config.xml，並在 manifest 宣告 android:localeConfig，這部分和原生 App 相同。
